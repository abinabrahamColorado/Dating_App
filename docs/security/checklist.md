# Security checklist

Source: the founder's exact 49-item list, transcribed from two screenshots and
provided in this chat on 2026-11-11. Scope: the current M0–M4 application and this
separate hardening PR (DEC-050/051). This is an evidence register, not a penetration
test certification or permission to enroll real people. “Covered” is limited to
the named code and tests. “Open” names the remaining action and owner; partial
controls are described without claiming complete coverage. Absent features are
not applicable and must be reassessed if introduced.

Paths below are repository-relative. Tests use synthetic data and real PostgreSQL.
